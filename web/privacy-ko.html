요약

Faithful parents는 묵상집 아버지처럼과 어머니가 위로하듯을 담은 앱으로, 계정도, 통계도, 광고도, 추적도 없습니다. 쿠키를 저장하지 않고 이용자 프로필도 만들지 않습니다. 읽기 진행 상황과 설정은 기기에 남습니다. 데이터는 아래에 적은 서비스로만, 각 기능에 필요한 범위에서만 전달됩니다.

호스팅과 낭독 (GitHub Pages)

앱의 웹 버전과 녹음된 낭독은 GitHub, Inc.(88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA)의 서비스인 GitHub Pages를 통해 제공됩니다. 웹 버전을 열거나 앱이 녹음된 낭독을 재생하거나 내려받을 때, GitHub는 파일을 전달하고 서비스를 보호하는 데 필요한 기술 정보, 특히 IP 주소, 날짜와 시각, 요청된 주소, 브라우저나 기기에 관한 정보를 처리합니다. iPhone 앱의 본문은 앱 안에 저장되어 있으며, 앱은 낭독을 위해서만 GitHub에 접속합니다.

법적 근거는 GDPR 제6조 제1항 (f)호이며, 우리의 정당한 이익은 앱과 낭독을 안전하고 안정적으로 제공하는 것입니다. GitHub는 EU-미국 데이터 프라이버시 프레임워크 인증을 받았습니다(GDPR 제45조). GitHub 개인정보 보호 정책을 참고하세요.

기기에 저장되는 데이터

읽기 계획, 읽음으로 표시한 날, 마지막으로 연 날, 언어, 글자 크기와 글꼴, 밝은 모드나 어두운 모드, 알림 시각, 음성 설정은 기기에 저장되며, 오프라인으로 들으려고 내려받은 낭독도 마찬가지입니다. 웹 버전은 오프라인 읽기를 위해 자기 사본을 저장하고, 설치 안내를 닫았는지도 기억합니다. 이 데이터는 기기를 떠나지 않습니다. 저장은 이용자가 요청한 기능에 반드시 필요합니다(TDDDG 제25조 제2항 제2호). 설정의 진행 상황 항목에서, 브라우저의 사이트 데이터를 지워서, 또는 앱을 삭제해서 지울 수 있습니다.

알림과 소리 내어 읽기

iPhone이나 Android 앱에서 매일 알림을 켜면 알림은 휴대폰 자체가 예약하며, 우리나 어떤 서버로도 아무것도 전송되지 않습니다. 앱이 기기의 음성으로 읽을 때에는 운영체제가 기기 안에서 음성을 만듭니다.

성경 본문 링크

날마다 해당 성경 본문으로 연결되는 링크가 있을 수 있습니다. 한국어, 영어, 스페인어, 프랑스어, 포르투갈어, 러시아어는 BibleGateway.com, 독일어는 bibleserver.com, 터키어는 bible.com(YouVersion)으로 연결됩니다. 데이터는 이용자가 그런 링크를 누를 때에만 해당 사이트로 전달되며, 본문은 브라우저에서 열리고 그 사이트의 개인정보 처리방침이 적용됩니다.

이메일 문의

이메일을 보내 주시면 답변을 위해 이메일 주소와 메시지 내용을 처리합니다. 법적 근거는 문의가 협업에 관한 것일 때는 GDPR 제6조 제1항 (b)호, 그 밖에는 (f)호이며, 우리의 정당한 이익은 문의에 답하는 것입니다. 메시지는 처리가 끝나고 보관 의무가 없으면 삭제합니다.

이용자의 권리

이용자는 열람권(GDPR 제15조), 정정권(제16조), 삭제권(제17조), 처리 제한권(제18조), 데이터 이동권(제20조), 그리고 정당한 이익에 근거한 처리에 대한 이의권(제21조)을 가집니다. 위 이메일 주소로 보내 주세요. 또한 개인정보 감독 기관에 민원을 제기할 수 있으며(GDPR 제77조), 관할 기관은 바이에른주 개인정보 보호 감독청(BayLDA, Promenade 18, 91522 Ansbach, 독일)입니다.
